# Анализатор зависимостей Java-пакетов

## Описание проекта

Программа предназначена для анализа зависимостей Java-пакетов из Maven-репозитория.

Она позволяет получать прямые зависимости пакета, строить полный граф зависимостей, определять порядок загрузки и визуализировать результат.

## Используемые технологии

- Python 3.12
- PyYAML — чтение конфигурационного файла YAML
- urllib — загрузка POM-файлов из Maven-репозитория
- ElementTree — разбор XML-файлов
- JSON — хранение тестовых данных
- unittest — автоматическое тестирование

## Структура проекта

- `src/main.py` — главный файл запуска программы.
- `src/config.py` — загрузка и проверка конфигурации.
- `src/maven.py` — получение прямых зависимостей из Maven POM-файлов.
- `src/graph.py` — построение графа зависимостей с помощью DFS.
- `src/visualizer.py` — вывод ASCII-дерева и создание PlantUML-файла.
- `config.yaml` — настройки программы.
- `tests/` — тестовые данные и автоматические тесты.
- `requirements.txt` — список необходимых сторонних библиотек.

## Установка

Установить необходимые зависимости:

```bash
python -m pip install -r requirements.txt
```

## Настройка

Перед запуском необходимо открыть файл `config.yaml`.

Основные параметры:

- `package` — название или координаты Java-пакета.
- `repository` — URL Maven-репозитория.
- `test_mode` — включение или отключение тестового режима.
- `test_file` — путь к файлу с тестовыми зависимостями.
- `max_depth` — максимальная глубина обхода зависимостей.
- `ascii_tree` — включение или отключение ASCII-дерева.
- `plantuml_file` — имя файла для сохранения графа PlantUML.

В тестовом режиме используются пакеты с названиями из больших латинских букв.

В реальном режиме пакет указывается в формате `groupId:artifactId:version`.

## Запуск программы

Из корневой папки проекта выполнить:

```bash
python src/main.py
```

## Тестирование

Для запуска автоматических тестов выполнить:

```bash
python -m unittest discover -s tests -v
```

## Основные возможности

1. Чтение и проверка настроек из YAML.
2. Получение прямых зависимостей Java-пакетов.
3. Построение графа зависимостей с помощью рекурсивного DFS.
4. Обнаружение циклических зависимостей.
5. Ограничение глубины обхода.
6. Определение порядка обхода зависимостей.
7. Вывод дерева зависимостей в консоль.
8. Генерация графа в формате PlantUML.

## Результат работы

После запуска программа выводит настройки, прямые зависимости, построенный граф и порядок загрузки зависимостей.

Также создаётся файл PlantUML с описанием графа зависимостей.
